# Known Faces Directory

Place photos of registered users in this directory.

- **File Naming Format**: `Firstname_Lastname.jpg` or `Name.png` (e.g., `John_Doe.jpg` or `Alice.png`).
- The system will automatically convert underscores `_` to spaces and load encodings for face recognition.
- You can also register faces directly through the Web Dashboard UI via the **"Register Face"** button!
